# Coin Change Machine

Verilog kullanılarak tasarlanmış senkron bir **Para Bozdurma Otomatı** projesidir.

### Features

* 7-bit giriş ile 1–99 KR arası değerleri işler.
* Parayı 50, 25, 5 ve 1 KR olarak bozar.
* Comparator, Subtractor, Register ve Counter modülleri kullanılmıştır.
* Clock ve Reset desteği bulunmaktadır.
* Tasarım tamamen Verilog ile gerçekleştirilmiştir.

### Example

**78 KR → 1×50 KR + 1×25 KR + 3×1 KR**

### Results

* Maximum Frequency: **201.73 MHz**
* Combinational Logic: **58**
* I/O Pins: **61**
